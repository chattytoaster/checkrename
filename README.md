# CheckRename — Автоматическое переименование PDF-счетов

Утилита для Windows, предназначенная для автоматического переименования входящих счетов на оплату в формате PDF, мониторинга папки «Загрузки» и интеграции с контекстным меню Проводника (ПКМ).

---

## Возможности

- **Фоновый мониторинг**: приложение работает в системном трее (возле часов) и отслеживает появление новых файлов в папке Загрузок.
- **Интеллектуальное распознавание счетов**:
  - Быстрое извлечение данных из цифрового текстового слоя PDF (1С, банк-клиент, типовые счета).
  - OCR-распознавание сканов и изображений (Tesseract) при отсутствии текстового слоя.
  - Извлечение номера счета, даты составления и наименования организации-поставщика (с автоматическим сокращением ОПФ: «ООО», «ИП», «АО»).
- **Контекстное меню Windows (ПКМ)**:
  - Пункт **«Найти номер счета»** при правом клике на любой PDF-файл.
  - Мгновенно находит номер, переименовывает файл по шаблону и показывает всплывающее уведомление Windows.
  - Автоматическая регистрация при первом запуске (не требует захода в настройки).
- **Гибкий шаблонизатор названий**:
  - По умолчанию: `Счет №{number} ({org} - {date})`
  - Переменные:
    - `{number}` — номер счета;
    - `{date}` — дата счета;
    - `{org}` — поставщик/исполнитель;
    - `{original}` — исходное название файла.
  - Автоматическое разрешение конфликтов имен: добавление суффиксов `(1)`, `(2)` при дубликатах.
- **Управление файлами**:
  - Переименование на месте в папке загрузок ИЛИ автоматическое перемещение в указанную папку (например, `Документы/Счета`).
- **Отмена переименования (Undo)**:
  - Пункт в меню трея для отмены последнего переименования и возврата файла к исходному имени/месту.
- **Автозапуск**: опция запуска при входе в Windows.

## Запуск из исходного кода

1. Откройте проект:
   ```powershell
   cd C:\Users\ChattyNB\projects\docrename
   ```

2. Активируйте виртуальное окружение:
   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

3. Запустите приложение:
   ```powershell
   python -m checkrename.main
   ```
   После запуска в области уведомлений Windows (системный трей) появится иконка документа с зеленым индикатором статуса.

4. Чтобы открыть окно настроек напрямую:
   ```powershell
   python -m checkrename.main --settings
   ```
